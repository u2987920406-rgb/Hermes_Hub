# Hermes Hub

## Identite

Interface web locale qui pilote une equipe d'agents IA. Serveur Node sans
dependance, interface React construite par Vite. Le developpement vit sur la
branche `v2` ; `main` reste figee sur la version livree aux clients.

## Regles

- **Aucune commande git sans accord explicite.** Ni `add`, ni `commit`, ni
  `push`. Le depot versionne `dist/`.
- **Chaque commit finit par une ligne `Ensuite :`** - les deux prochains coups,
  une phrase chacun. Le journal dit ce qui a ete fait ; cette ligne est le seul
  endroit ou vit ce qui etait prevu.
- **Le point de reprise se lit dans `git log -1`, pas dans un fichier.** Un
  memo de reprise tenu a la main rote quand la seance s'arrete mal, donc pile
  quand il servirait. Ne pas en creer.
- **`npm run build` apres toute modification de `src/`** : le serveur sert
  `dist/`, pas `src/`.
- **Lire `DESIGN.md` avant de toucher a l'interface** - la plupart des retouches
  se reglent avec une molette dans `src/index.css`, sans ouvrir un `.tsx`.

## Voir aussi
